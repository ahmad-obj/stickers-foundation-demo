# Stickers Corporation v1.1 — Composition and Motion Refinement

Source of intent: user-approved implementation plan supplied 15 November 2026. Supersedes the earlier v1.1 sticker-studio concept.

Preserve the approved typography, paper/ink/yellow palette, authentic photography, business content and inquiry workflow. Keep the demo local and unindexed. Add no dependencies, sections, fabricated content or deployment.

## Composition

- Remove the sticker studio, its links, drag hook, styles, tests and optional quotation field/event/message integration. Restore the hero secondary action to “Request a quote.”
- Hero: 1.25fr / 1fr desktop composition, 32–64px fluid gap, centred photograph, contained stage capped at 600px or 62vh.
- Retain manual photo selection; refine spacing, selected states and aligned captions.
- Balanced desktop portfolio columns without negative margins; preserve source orientations and single-column mobile visual/keyboard order.
- Expanded mobile services include their relevant image and explanation; retain desktop sticky imagery.
- Desktop form text 14px, labels 12px, consistent control heights and spacing.
- Active-section navigation underline; shared grid alignment for about, quotation and footer.

## Motion

- One signature hero interaction on precise hover pointers: distance-based letter wave, up to 6px lift and 2° rotation, restrained offset ink, frame perspective up to 3°, 500ms return to rest.
- Hero letter entrance under one second. Selected heading reveals: 550ms, 12px travel, stagger capped at 250ms. Static paragraphs.
- Consistent cubic-bezier(.16,1,.3,1); restrained link underlines and action arrows. Portfolio image/title/inquiry hover coordinated, image scale 1.02.
- Coordinated image/copy selection exits and entrances. Interruptible gallery filtering with immediate fallback.
- Mobile menu and viewer: 250ms entrance, 180ms exit. Horizontal viewer swipe, visible controls, keyboard access and focus restoration. Disable cycling in single-photo categories.
- Native CSS, IntersectionObserver and bounded pointer updates through refs/requestAnimationFrame. Semantic heading names survive text splitting. Reduced motion removes decoration and makes state changes immediate.
