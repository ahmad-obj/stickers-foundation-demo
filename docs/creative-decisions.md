# Print Lab creative decisions

These are historical composition choices for the implemented first surface, not extra global design rules. The canonical current system is DESIGN.md.

The initial hero exploration considered three approaches:

1. **Vinyl peel:** physically relevant, but it risked obscuring authentic work and making the opening a novelty.
2. **Full-photo hero:** offered immediate authenticity, but the available shop lighting weakened full-bleed copy legibility.
3. **Editorial headline with Cheezy sign:** selected. The two-line tagline uses a smaller opening line and a yellow printed block for the second line. A portrait photograph reads as a physical print, alongside a clear service description and two distinct actions.

The original logo and location link support recognition and trust. The page moves through service navigation, an asymmetric work gallery, a service index with context imagery, photographed materials, a short business introduction, a guided inquiry and contact details. This sequence is the current page strategy, not a requirement for every future screen.

Native CSS motion, native dialog semantics and plain controls were selected for this image-led site. Real material photography makes WebGL unnecessary. Early provisional dimensions and timings were replaced in DESIGN.md with the values extracted from the implementation.

This record does not approve public deployment. PRODUCT.md retains the local-demo scope and source/content requirements.
